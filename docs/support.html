케세헌 고객 지원

케세헌은 K-SALES HUNTER 판매 현황(순이익, 마진율, 매출 추이, 최근 상품)을 휴대폰에서 확인하는 조회 전용 앱입니다. 상품 등록, 분석 보고서, 판매 관리는 PC 웹에서 이용할 수 있습니다.

자주 묻는 질문

계정은 어떻게 만드나요?
K-SALES HUNTER 웹에서 가입한 계정으로 앱에 로그인합니다.

계정 정보나 마켓 설정을 바꾸고 싶어요.
PC 웹의 설정 메뉴에서 바꿀 수 있습니다.

다크 모드를 쓰고 싶어요.
앱 설정 → 화면 → 테마에서 시스템 / 라이트 / 다크를 고를 수 있습니다.

문의하기

GitHub 문의 게시판에 남겨 주시면 확인 후 답변드립니다.
